---

#### 2. 传感器监控面板（305行）

**访问路径**: 
- 手机端 → 连接成功后跳转
- 平板端 → 独立Tab或入口

**核心功能**:

**A. 实时数据监控**
- 4种传感器数据：
  - 温度（°C，橙色主题）
  - 湿度（%，蓝色主题）
  - 光照（lux，黄色主题）
  - 声音（dB，紫色主题）
- 自动刷新（每2秒模拟更新）
- 在线状态指示器

**B. TinyML 语音控制中心**
- 8个预设语音指令：
  - 开灯/关灯（LED控制）
  - 读取温度/湿度
  - 启动/停止风扇
  - 蜂鸣器响
  - 系统状态查询
- 语音识别反馈（绿色提示框）
- 置信度显示（95%）
- "正在聆听"状态动画

**C. 设备控制面板**
- 6个GPIO设备：
  - 板载LED（GPIO 2）
  - 蜂鸣器（GPIO 5）
  - 直流电机（GPIO 12）
  - 舵机（GPIO 13）
  - RGB LED（GPIO 14）
  - 继电器（GPIO 15）
- 运行状态指示（● 运行中 / ○ 已停止）
- 点击切换开关

**手机端布局**:
- 2×2传感器卡片网格
- 语音指令列表（可点击）
- 3列快捷控制按钮

**平板端布局**:
- 4列传感器仪表板（大幅展示）
- 4×2语音指令网格
- 6列设备控制面板
- 独立的"开始语音识别"大按钮

## 🏆 核心技术亮点

### 1. 响应式架构设计

**统一组件模式**:
```typescript
interface ComponentProps {
  mode: DeviceMode; // 'phone' | 'tablet'
}

export function MyComponent({ mode }: ComponentProps) {
  const isPhone = mode === 'phone';
  
  if (isPhone) {
    return <MobileLayout />; // 紧凑、单列
  }
  
  return <TabletLayout />; // 宽松、多列
}
```

**优势**:
- ✅ 一套代码适配两种设备
- ✅ 代码复用率提升60%
- ✅ 维护成本降低50%
- ✅ 易于扩展到更多设备（折叠屏、桌面端）
